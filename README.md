# RentEase - Rental Booking Platform

A full-stack property rental booking platform with admin and tenant dashboards.

## Features
- Property listing with search and filters
- User authentication (Admin & Tenant)
- Booking request system
- Image upload for properties
- Admin dashboard for managing properties and bookings

## Tech Stack
- Backend: Flask, MongoDB, JWT
- Frontend: HTML5, CSS3, JavaScript, Bootstrap
- Deployment: Docker / Railway / Render

## Setup Instructions
1. Clone the repository
2. Install Python dependencies: `pip install -r requirements.txt`
3. Set up MongoDB locally or use MongoDB Atlas
4. Copy `.env.example` to `.env` and update values
5. Run backend: `python backend/server.py`
6. Access at `http://localhost:5000`
